# SeaJobs - Морская Кадровая Платформа

SeaJobs - это веб-платформа для поиска работы и найма персонала в морской отрасли.

## Архитектура проекта

Проект состоит из следующих компонентов:

- **Frontend**: React приложение
- **Backend**: Django REST API
- **База данных**: PostgreSQL
- **Хранилище файлов**: MinIO (S3-совместимое)
- **Веб-сервер**: Nginx

## Требования для локального запуска

- Docker
- Docker Compose
- Git

## Как запустить локально

### 1. Клонировать репозиторий

```bash
git clone <url-вашего-репозитория>
cd seabroker
```

### 2. Запустить с помощью скрипта

```bash
./run-local.sh
```

Этот скрипт выполнит следующие действия:
- Соберет frontend приложение
- Запустит все контейнеры через Docker Compose
- Создаст базу данных и необходимые таблицы
- Инициализирует MinIO bucket для хранения файлов
- Создаст суперпользователя для администрирования

### 3. Доступ к приложению

После успешного запуска, вы можете получить доступ к:

- Веб-приложению: http://localhost
- Панели администратора: http://localhost/admin
- MinIO консоли: http://localhost/minio

## Замечания по развертыванию в production

При развертывании в production среде рекомендуется:

1. Изменить все пароли и ключи в .env файле
2. Настроить SSL сертификаты для Nginx
3. Изменить SECRET_KEY в настройках Django
4. Установить DEBUG=0 для отключения режима отладки
5. Настроить резервное копирование базы данных и файлов

## Решение проблем

### Проблемы с доступом к MinIO

Если у вас возникли проблемы с MinIO, проверьте:
1. Создан ли bucket с правильным именем
2. Правильно ли указаны ACCESS_KEY и SECRET_KEY
3. Включена ли опция USE_S3=True в .env файле

### Проблемы с фронтендом

Если фронтенд не отображается:
1. Проверьте, что сборка фронтенда успешно создана в frontend/build
2. Проверьте логи Nginx на наличие ошибок
